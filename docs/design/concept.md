# Design Concept

The primary surface is a three-pane transcription editor:

- Left: upload, MLX model settings, diarization controls, and local job list.
- Center: selected audio job, progress, audio player, and timestamped transcript segments.
- Right: detected speaker identities, rename fields, and export actions.

The visual system uses an off-white canvas, white editor surfaces, charcoal text, teal primary actions, amber progress accents, compact controls, 8px-or-smaller radii, and icon-led buttons where helpful.
